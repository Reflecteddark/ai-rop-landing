## 🚀 Ключевые интерактивные модули на сайте:

1. **Интерактивный ROI-калькулятор (As-Is vs To-Be)**:
   - Ползунки: Поток лидов (150), Средний чек (400 000 ₽), Менеджеров ОП (4 чел).
   - Расчет емкости воронки, упущенной прибыли и трех сценариев роста (+15%, +30%, +50%).
   - Расшифровка 4 узких мест воронки продаж и окупаемости за первые 30 дней.

2. **Модуль скачивания демо-отчета (Excel)**:
   - Кнопка «Скачать пример отчета (Excel)» моментально отдает файл `RevOps_Platform_Demo_Sample.xlsx`.
   - Таблица полностью зеркалит эталонную книгу фаундера (**RevOps Platform V17.5 Golden Master**), включая вкладку **«ИИ-Аудит» с 13 критериями оценки диалогов** и **«Пульт РОПа: 5 решений месяца»**.

3. **Лид-магнит и связка с Telegram-ботом**:
   - Кнопка «Пройти бесплатный тест-драйв на 3 звонках» ведет напрямую в боевого бота [@RevOps_Super_Audit_Bot](https://t.me/RevOps_Super_Audit_Bot).

4. **Блок доверия и 152-ФЗ РФ**:
   - Гарантия локализации баз данных в РФ (Selectel / Yandex Cloud УЗ 1-2).
   - Криптографическая токенизация ПДн (`PIISanitizer`).
   - Удаление аудио через 30 дней, работа по 422-ФЗ (Самозанятый, 0% НДС, чек «Мой Налог»).

## 🛠️ Как вносить изменения в сайт

1. Откройте `web/index.html`.
2. Отредактируйте нужный текст, заголовок или контакты.
3. Сохраните файл и выполните git push в ветку `main`.
4. Изменения автоматически публикуются на домене **[ai-rop.ru](https://ai-rop.ru)**.
